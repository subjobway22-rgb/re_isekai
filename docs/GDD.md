# 리:이세계 (RE: ISEKAI) — 게임 기획서 v0.2

> 웹 기반 횡스크롤 방치형 RPG. 트럭에 치이고 편의점 앞에서 눈을 떠보니 이세계였다.

## 1. 한 줄 요약
**"편의점 앞에서 시작하는 이세계 모험"** — 캐릭터·파트너를 고르고 이세계를 자동 전진하며 슬라임·고블린·스켈레톤을 사냥, 공격력 강화와 랜덤 옵션 악세사리로 성장하는 방치형 게임. **좋아하는 아이돌·애니 캐릭터(최애)를 파트너로 데려가고, 모험 중 다른 플레이어와 랜덤으로 마주쳐 대결하거나 서로 돕는 것**이 게임의 감성 포인트.

| 항목 | 내용 |
|---|---|
| 플랫폼 | 웹(PC/모바일 브라우저), 세로·가로 반응형 |
| 장르 | 횡스크롤 방치형(Idle) RPG |
| 세션 | 짧게 확인 + 길게 방치 (오프라인 보상 최대 8h) |
| 아트 | 도트(픽셀) 2D, 따뜻한 팔레트 |
| 기술 스택(제안) | HTML5 Canvas + TypeScript, 저장은 LocalStorage → 추후 서버 |

## 2. 오프닝 시나리오 (튜토리얼 겸용)
1. **암전** → 트럭 경적음 → 쾅.
2. 텍스트: *"……여긴 어디지?"*
3. 편의점 간판이 깜빡이는 초원 한복판. 주인공이 눈을 뜬다. *"아… 나 트럭에 치이고 편의점 앞에서 정신을 잃었는데… 이세계?!"*
4. **이름 입력** (2~8자, 금칙어 필터)
5. **캐릭터 선택**: 외형 4종 (전사 / 궁수 / 마법사 / 도적 — 외형·초기 보정 약간 차이)
6. **파트너(최애) 만들기**: 이름·분류·외형·성격·대사를 직접 입력 (아래 5장)
7. "모험을 떠나자!" → 첫 전투 자동 시작 (슬라임)

## 3. 핵심 루프
```
자동 이동 → 몬스터 조우 → 자동 전투 → 골드/재료/드랍 획득
   ↑                                         ↓
 더 깊은 스테이지  ←  보스 클리어  ←  강화(공격력) · 악세사리 뽑기/강화
```
- **단기(10초)**: 몬스터 처치, 골드 숫자 상승, 파트너의 응원 대사
- **랜덤 이벤트(수 분마다)**: 다른 플레이어와 조우 → 대결 / 나눔 / 회복 / 버프 / 무기 강화 (5-2장)
- **중기(5~10분)**: 강화 구매, 악세사리 획득, 보스 도전
- **장기(일 단위)**: 지역 해금, 악세사리 세트, 환생(프레스티지)

## 4. 전투 시스템 (자동)
- 캐릭터가 오른쪽으로 걷다가 몬스터와 마주치면 정지 → 자동 공격 → 처치 시 다시 이동.
- 스테이지당 몬스터 10마리 + 보스 1마리. 보스는 30초 제한시간, 실패 시 직전 스테이지 반복.
- **탭 보너스**: 화면 터치 시 추가 데미지 소량(능동 플레이 보상, 방치 효율을 넘지 않게).
- 전투 스탯: 공격력(ATK), 공격속도(AS), 치명타 확률(CRIT), 치명타 피해(CDMG), 체력(HP), 방어(DEF), 골드 획득(GOLD%), 드랍률(DROP%)

### 몬스터 (지역별)
| 지역 | 스테이지 | 일반 몬스터 | 보스 |
|---|---|---|---|
| 1. 시작의 초원 | 1~30 | 슬라임, 뿔토끼, 버섯 | 킹슬라임 |
| 2. 고블린 숲 | 31~60 | 고블린, 늑대, 고블린 궁수 | 고블린 대장 |
| 3. 잊혀진 묘지 | 61~90 | 스켈레톤, 좀비, 유령 | 리치 |
| 4. 용암 동굴 | 91~120 | 불도마뱀, 골렘 | 용암 드래곤 |
| 이후 | 확장 | 편의점 던전(이벤트 지역) 등 | — |

몬스터 HP 곡선: `HP(n) = 10 × 1.18^n` (보스는 ×8), 골드 보상: `10 × 1.15^n`

## 5. 파트너 (최애) & 플레이어 조우

### 5-1. 파트너 = 플레이어가 직접 지정하는 가상 캐릭터
파트너는 **플레이어가 직접 입력해서 만드는 가상의 아이돌/애니 캐릭터**. 정해진 파트너 목록은 없고, 오프닝에서 "함께 떠날 사람은?"이라는 질문에 직접 채워 넣는다. 성능은 보조고 애착이 중심.

**파트너 생성 입력 항목**
| 항목 | 입력 방식 | 용도 |
|---|---|---|
| 이름 | 직접 입력 (2~10자) | 대사창·조우 화면 표기 |
| 분류 | 아이돌 / 애니 캐릭터 / 기타 중 선택 | 응원 대사 기본 톤, 스킬 연출 테마 |
| 외형 | **도트 파츠 조합 + 파츠별 색상 변경** (아래 외형 커스터마이저 참고). 이미지 업로드는 지원하지 않음 | 전투 뷰 동행 아바타 |
| 성격/말투 | 선택(상냥/츤데레/쿨/활발 등) + 직접 입력 | 자동 대사 생성 틀 |
| 응원 대사 | 직접 입력 5~10개 (비우면 성격 기반 기본 대사) | 전투 중 말풍선 |
| 소개 한 줄 | 직접 입력 | 조우 화면에서 상대에게 노출 |
| 테마 컬러 | 선택 | 프레임·이펙트 색 |
| 역할 타입 | 딜러 / 서포터 / 힐러 / 재물 | 스킬·스탯 보너스 |

- 파트너는 **슬롯 여러 개**(기본 1, 애정도·진행으로 확장)로 교체 가능, 수정도 언제든 가능
**외형 커스터마이저 (도트 파츠 + 색상)**
| 파츠 레이어 | 종류(초안) | 색상 변경 |
|---|---|---|
| 뒷머리 / 앞머리 / 머리 장식 | 각 8~12종 | 머리색 팔레트 16색 + 하이라이트 자동 |
| 얼굴·눈 | 눈 8종, 표정 3종 | 눈색 12색, 피부톤 6종 |
| 의상(상의/하의/원피스) | 각 8~10종 | 메인색·포인트색 각 16색 |
| 소품(마이크, 지팡이, 리본, 헤드셋, 고양이귀 등) | 12종 | 소품색 16색 |
| 이펙트 오라(스킬 연출) | 6종 | 테마 컬러 자동 적용 |

- 기본 파츠는 무료, 일부 파츠·고급 색상은 **인연 포인트/이벤트/젬으로 해금**(수집 요소)
- 색상 변경은 **팔레트 스왑 방식**: 파츠를 지정 키컬러(예: 머리 밝은색/중간색/어두운색 3톤)로 그려두고 코드에서 색을 치환 → 파츠 이미지 1벌로 모든 색 구현
- 무작위 버튼, 프리셋 저장 슬롯, 도트 미리보기(걷기/대기 애니)
- 조우 때 상대에게는 **파츠 ID + 색 코드만 전송**(이미지 전송 없음) → 서버 부담·부적절 이미지 위험 없음

- 직접 입력이므로 **욕설·혐오·실존 인물 실명 필터**(금칙어 + 신고)만 적용. 게임이 특정 IP 캐릭터를 직접 제공하지 않으니 별도 권리 처리는 불필요

**파트너 기능**
- **동행**: 전투 뷰에서 캐릭터 옆을 따라다니는 도트 아바타(파츠 조합 또는 업로드 이미지를 도트 변환 + 테마컬러 프레임)
- **응원 대사**: 플레이어가 입력한 대사가 말풍선으로 출력 (보스 등장·치명타·레벨업·방치 복귀 시 상황별)
- **애정도(호감도) 레벨**: 함께 전투·선물 시 상승 → 컷신/대사 해금, 영구 스탯 보너스
- **역할 타입** (직접 선택): 딜러(공격%) / 서포터(버프 지속↑) / 힐러(회복↑) / 재물(골드·드랍↑)
- **자동 스킬**: 타입별 1종 (쿨타임 8~12초), 애정도 올리면 강화
- **응원 콜**: 조우 이벤트에서 내 파트너가 상대 파트너에게 인사/응원 (5-2)

### 5-2. 랜덤 플레이어 조우 (비동기)
모험 중 일정 주기(평균 3~5분, 방치 중에도 발생)로 필드에 **"❓ 누군가 다가온다"** 이벤트 발생. 상대는 서버에 저장된 **다른 플레이어의 스냅샷(캐릭터 외형, 파트너, 전투력 요약)**이며, 실시간 접속이 필요 없음.

| 이벤트 | 확률(초안) | 내용 |
|---|---|---|
| ⚔️ 대결 | 30% | 상대 스냅샷과 자동 전투. 승리 시 골드·강화석·인연 포인트, 패배 시 소량 위로 보상(페널티 없음) |
| 🎁 나눔 | 25% | 상대가 재화를 나눠줌 (골드/강화석/재굴림석/젬 소량) |
| 💚 회복 | 15% | 상대 파트너가 HP/쿨타임 회복 |
| ✨ 버프 | 20% | 일정 시간(5~10분) 공격력%/공속%/치명타/골드% 중 1개 강화 |
| 🔨 무기 강화 | 10% | 상대가 무기를 손봐줌: 무기 강화 단계 +1 (확률) 또는 강화석 |

**상호 이득 구조**
- 나눔/회복/버프/무기 강화를 **받은 쪽도, 도움을 준 쪽(스냅샷 주인)도** 보상을 받음 (인연 포인트 🤝 + 소량 재화). 서로 만나면 이득이라 설계상 선순환.
- 조우 후 **"친구 신청"** 가능 → 친구가 되면 이후 조우 확률 ↑, 친구 파트너 응원 대사 교환
- **조우 기록(인연 도감)**: 만난 플레이어, 파트너, 받은/준 도움 횟수 기록 (최애 파트너 수집/감상 요소)
- 조우 때 상대의 **파트너 대사**가 노출 → "같은 최애를 키우는 사람" 만남의 재미 (같은 최애 태그면 보너스 확률)

**경제·어뷰징 방지**
- 재화는 **플레이어 간 실제 이전이 아니라 시스템이 생성**해서 양쪽에 지급 (다계정 재화 몰아주기 방지)
- 받는 보상 **일일 상한** (예: 조우 보상 20회/일), 같은 상대 반복 조우 감쇠
- 스냅샷에 닉네임/업로드 이미지 **신고·차단 기능**, 차단 시 이후 조우 제외
- 서버가 없는 초기 단계에서는 **NPC 스냅샷(봇)**으로 동일 이벤트 구현 → 서버 도입 시 실유저 스냅샷으로 교체

**UI 흐름**
1. 필드에 ❓ 말풍선 → 탭
2. 조우 팝업: 상대 캐릭터+파트너 도트, 닉네임, 파트너 대사 한 줄
3. 이벤트별 연출(대결 자동전투 / 선물 상자 / 회복 이펙트 / 버프 아이콘 / 모루 두드리는 연출)
4. 결과 + "친구 신청 / 신고 / 확인" 버튼

## 6. 성장 시스템

### 6-1. 공격력 강화 (골드) & 무기
- 메인 강화: **공격력 Lv.N** — 비용 `50 × 1.12^N`, 효과 `ATK = 5 + 3N`
- 보조 강화(골드): 공격속도, 치명타 확률, 치명타 피해, 체력 (각 상한 있음)
- **무기 강화 단계(+0~+20)**: 강화석으로 올리며 ATK 배율 증가. 조우의 '무기 강화' 이벤트로 +1 보너스
- **일괄 구매 버튼** ×1 / ×10 / ×MAX
- 마일스톤: Lv 25/50/100… 마다 공격력 ×2 보너스 (성장 체감용)

### 6-2. 악세사리 (핵심 수집 요소)
**슬롯**: 반지 / 목걸이 / 귀걸이 / 팔찌 / 벨트 (5슬롯)

**획득**: 몬스터 드랍(낮은 확률), 보스 확정 드랍, **소환(젬 사용)**

**등급**: 일반(회색) → 고급(초록) → 희귀(파랑) → 영웅(보라) → 전설(주황) → 신화(빨강)

**랜덤 옵션**: 등급별 옵션 개수 — 일반 1 / 고급 2 / 희귀 3 / 영웅 3(+고정) / 전설 4 / 신화 4(+고유효과)

옵션 풀 예시: ATK%, 공격속도%, 치명타 확률, 치명타 피해, HP%, 골드 획득%, 드랍률%, 파트너 스킬 쿨감, 보스 추가 피해%

**강화**
| 방식 | 재료 | 효과 |
|---|---|---|
| 레벨업 | 골드 + 강화석 | 모든 옵션 수치 +x% (Lv 최대 = 등급별 10~30) |
| 옵션 재굴림 | 재굴림석 | 옵션 1개 선택 → 다시 랜덤 (잠금 가능) |
| 합성 | 같은 등급 3개 | 상위 등급 1개 확률 획득 |
| 분해 | 불필요 악세 | 강화석 획득 |

**소환 천장**: 소환 90회 내 전설 이상 미획득 시 확정 (천장 카운트 UI 표시)

### 6-3. 지역 해금 · 환생
- 보스 클리어 시 다음 지역 해금.
- **환생(프레스티지)**: Stage 100+ 에서 가능, 스테이지·골드·공격력 강화를 리셋하고 **'이세계의 별'** 획득 → 영구 공격력/골드 보너스. (악세사리·파트너는 유지)

## 7. 방치 보상
- 접속 종료 시각 저장 → 복귀 시 `경과시간(최대 8h) × 분당 골드·드랍` 정산 팝업.
- 광고 대신 웹 환경 고려: 보상 2배 버튼은 **젬 소모** 또는 (추후) 광고.

## 8. 재화
| 재화 | 용도 | 획득 |
|---|---|---|
| 🪙 골드 | 공격력/스탯 강화 | 전투, 방치 |
| 💎 젬 | 악세사리 소환, 편의 기능 | 퀘스트, 보스 최초 클리어, 업적 |
| 🤝 인연 포인트 | 조우 상점(최애 선물, 한정 아이템), 친구 기능 | 플레이어 조우 |
| 🔩 강화석 | 악세사리 강화 | 분해, 보스 |
| 🎲 재굴림석 | 옵션 재굴림 | 이벤트, 일일 던전 |
| ⭐ 이세계의 별 | 환생 영구 보너스 | 환생 |
| ⚡ 에너지 | 던전 입장 | 시간 회복(30/30) |
| 🎀 선물 | 파트너 애정도 상승 | 퀘스트, 조우 |

## 9. 콘텐츠 / 메타
- **일일 퀘스트**: 몬스터 N마리, 강화 N회, 소환 1회 → 젬
- **업적**: 스테이지 도달, 악세 등급 수집
- **도감**: 몬스터/악세사리 수집 (수집 완료 시 영구 스탯)
- **던전(에너지 소모)**: 재굴림석/강화석 던전, 보스 러시
- **편의점 이벤트**: 컨셉 연결. 주기적으로 '편의점'이 이세계에 등장 → 한정 상점(기간 한정 악세사리)
- **랭킹**: 최고 스테이지 (서버 도입 이후)
- (후순위) 시즌 패스, 미니게임, 우편함

## 10. UI / 디자인 가이드 (첨부 이미지 참고)

### 레퍼런스 분석
- **이미지 1 (DS풍 도트 RPG)** → 따뜻하고 통통한 도트 캐릭터, 밝은 초원 배경(원경 바위산·구름 패럴랙스), **하단에 갈색·황금 테두리 패널**, 노란 포인트 라벨(아이템 획득 띠), 네모난 아이콘 카드 슬롯.
- **이미지 2 (모바일 방치형)** → 상단 재화 바(⚡ 🪙 💎), 중앙 캐릭터 + 웨이브 배너(리본), 좌우 세로 아이콘 메뉴, 큰 노란 **START 버튼**, 하단 5탭 네비게이션.

### 합성 방향
- **화면 구조(세로 모바일 기준)**
  1. 상단 HUD: 프로필·레벨 / ⚡에너지 / 🪙골드 / 💎젬 / 설정
  2. 전투 뷰(상단 약 45%): 횡스크롤 필드, 스테이지 리본 배너(`STAGE 1-3`), 몬스터 HP 바, 데미지 숫자
  3. 좌우 아이콘 메뉴: 퀘스트·이벤트·랭킹·편의점 상점 등 (이미지 2 방식)
  4. 하단 패널(55%): 이미지 1의 **갈색 우드+황금 테두리** 프레임 안에 탭 콘텐츠
  5. 최하단 탭 5개: **성장 / 악세사리 / 모험(전투 홈) / 파트너 / 상점**
- **PC 화면**: 가운데 모바일 비율(9:16) 프레임 고정 + 양옆 배경 일러스트.

## 11. 수치 밸런스 초안
| 항목 | 공식 |
|---|---|
| 플레이어 DPS | `ATK × AS × (1 + CRIT×CDMG)` × 악세 보정 |
| 스테이지 n 몬스터 HP | `10 × 1.18^n` |
| 공격력 강화 비용(Lv N) | `50 × 1.12^N` |
| 악세 강화 비용(Lv N) | `100 × 1.25^N` 골드 + 강화석 |
| 등급 확률(소환) | 일반 45 / 고급 30 / 희귀 17 / 영웅 6 / 전설 1.8 / 신화 0.2 (%) |
| 오프라인 | 최대 8시간, 효율 70% |

목표 페이싱: 초반 5분 안에 스테이지 5, 첫 악세사리 획득, 첫 보스 도전.

## 13. 리스크 & 열린 질문
- 수익 모델: 광고/젬 결제/무과금 중 무엇으로 갈지 (현재 설계는 젬 중심)
- 서버 유무: 초기엔 LocalStorage → 치팅 대비 필요 시 서버 검증
- 악세사리 소환 확률 공개 (규제/신뢰 이슈 — 확률 표기 필수)
- 파트너 텍스트(이름·소개·대사)가 조우 화면에서 **다른 플레이어에게 노출**되므로 금칙어 필터·신고·차단 필요. 외형은 **도트 파츠 + 색상만 허용(결정됨)**이라 이미지 검수는 불필요
- 조우를 위한 서버 비용/지연: 스냅샷 방식(비동기)으로 최소화 가능
- 같은 최애 태그 매칭: 파트너 이름 자유 입력이라 동일성 판정이 어려움 → "분류 + 성격 타입"이나 선택형 태그로 매칭
