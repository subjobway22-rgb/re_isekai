# 리:이세계 (RE: ISEKAI) — 게임 기획서 v0.1

> 웹 기반 횡스크롤 방치형 RPG. 트럭에 치이고 편의점 앞에서 눈을 떠보니 이세계였다.

## 1. 한 줄 요약
**"편의점 앞에서 시작하는 이세계 모험"** — 캐릭터·파트너를 고르고 이세계를 자동 전진하며 슬라임·고블린·스켈레톤을 사냥, 공격력 강화와 랜덤 옵션 악세사리로 성장하는 방치형 게임.

| 항목 | 내용 |
|---|---|
| 플랫폼 | 웹(PC/모바일 브라우저), 세로·가로 반응형 |
| 장르 | 횡스크롤 방치형(Idle) RPG |
| 세션 | 짧게 확인 + 길게 방치 (오프라인 보상 최대 8h) |
| 아트 | 도트(픽셀) 2D, 따뜻한 팔레트 |
| 기술 스택(제안) | HTML5 Canvas + TypeScript, 저장은 LocalStorage → 추후 서버 |

## 2. 오프닝 시나리오 (튜토리얼 겸용)
1. **암전** → 트럭 경적음 → 쾅.
2. 텍스트: *"……여긴 어디지?"*
3. 편의점 간판이 깜빡이는 초원 한복판. 주인공이 눈을 뜬다. *"아… 나 트럭에 치이고 편의점 앞에서 정신을 잃었는데… 이세계?!"*
4. **이름 입력** (2~8자, 금칙어 필터)
5. **캐릭터 선택**: 외형 4종 (전사 / 궁수 / 마법사 / 도적 — 외형·초기 보정 약간 차이)
6. **파트너 선택**: 3종 (아래 5장)
7. "모험을 떠나자!" → 첫 전투 자동 시작 (슬라임)

## 3. 핵심 루프
```
자동 이동 → 몬스터 조우 → 자동 전투 → 골드/재료/드랍 획득
   ↑                                         ↓
 더 깊은 스테이지  ←  보스 클리어  ←  강화(공격력) · 악세사리 뽑기/강화
```
- **단기(10초)**: 몬스터 처치, 골드 숫자 상승
- **중기(5~10분)**: 강화 구매, 악세사리 획득, 보스 도전
- **장기(일 단위)**: 지역 해금, 악세사리 세트, 환생(프레스티지)

## 4. 전투 시스템 (자동)
- 캐릭터가 오른쪽으로 걷다가 몬스터와 마주치면 정지 → 자동 공격 → 처치 시 다시 이동.
- 스테이지당 몬스터 10마리 + 보스 1마리. 보스는 30초 제한시간, 실패 시 직전 스테이지 반복.
- **탭 보너스**: 화면 터치 시 추가 데미지 소량(능동 플레이 보상, 방치 효율을 넘지 않게).
- 전투 스탯: 공격력(ATK), 공격속도(AS), 치명타 확률(CRIT), 치명타 피해(CDMG), 체력(HP), 방어(DEF), 골드 획득(GOLD%), 드랍률(DROP%)

### 몬스터 (지역별)
| 지역 | 스테이지 | 일반 몬스터 | 보스 |
|---|---|---|---|
| 1. 시작의 초원 | 1~30 | 슬라임, 뿔토끼, 버섯 | 킹슬라임 |
| 2. 고블린 숲 | 31~60 | 고블린, 늑대, 고블린 궁수 | 고블린 대장 |
| 3. 잊혀진 묘지 | 61~90 | 스켈레톤, 좀비, 유령 | 리치 |
| 4. 용암 동굴 | 91~120 | 불도마뱀, 골렘 | 용암 드래곤 |
| 이후 | 확장 | 편의점 던전(이벤트 지역) 등 | — |

몬스터 HP 곡선: `HP(n) = 10 × 1.18^n` (보스는 ×8), 골드 보상: `10 × 1.15^n`

## 5. 파트너
선택 시 **패시브 + 자동 스킬** 제공. 전투에 함께 등장(캐릭터 뒤에서 따라다님). 이후 추가 획득/교체 가능.

| 파트너 | 컨셉 | 패시브 | 자동 스킬(쿨타임) |
|---|---|---|---|
| 🐱 냥타(고양이) | 민첩 | 공격속도 +10% | 할퀴기 연타 (8초) |
| 🐺 늑돌(새끼 늑대) | 돌격 | 치명타 확률 +8% | 돌진 물기, 단일 대폭딜 (10초) |
| 🐣 슬라(아기 슬라임) | 수비/재물 | 골드 획득 +15% | 슬라임 방패, 피해 흡수 (12초) |

파트너 레벨업: 전용 재료 '파트너 쿠키'(몬스터 드랍) 소모.

## 6. 성장 시스템

### 6-1. 공격력 강화 (골드)
- 메인 강화: **공격력 Lv.N** — 비용 `50 × 1.12^N`, 효과 `ATK = 5 + 3N`
- 보조 강화(골드): 공격속도, 치명타 확률, 치명타 피해, 체력 (각 상한 있음)
- **일괄 구매 버튼** ×1 / ×10 / ×MAX
- 마일스톤: Lv 25/50/100… 마다 공격력 ×2 보너스 (성장 체감용)

### 6-2. 악세사리 (핵심 수집 요소)
**슬롯**: 반지 / 목걸이 / 귀걸이 / 팔찌 / 벨트 (5슬롯)

**획득**: 몬스터 드랍(낮은 확률), 보스 확정 드랍, **소환(젬 사용)**

**등급**: 일반(회색) → 고급(초록) → 희귀(파랑) → 영웅(보라) → 전설(주황) → 신화(빨강)

**랜덤 옵션**: 등급별 옵션 개수 — 일반 1 / 고급 2 / 희귀 3 / 영웅 3(+고정) / 전설 4 / 신화 4(+고유효과)

옵션 풀 예시: ATK%, 공격속도%, 치명타 확률, 치명타 피해, HP%, 골드 획득%, 드랍률%, 파트너 스킬 쿨감, 보스 추가 피해%

**강화**
| 방식 | 재료 | 효과 |
|---|---|---|
| 레벨업 | 골드 + 강화석 | 모든 옵션 수치 +x% (Lv 최대 = 등급별 10~30) |
| 옵션 재굴림 | 재굴림석 | 옵션 1개 선택 → 다시 랜덤 (잠금 가능) |
| 합성 | 같은 등급 3개 | 상위 등급 1개 확률 획득 |
| 분해 | 불필요 악세 | 강화석 획득 |

**소환 천장**: 소환 90회 내 전설 이상 미획득 시 확정 (천장 카운트 UI 표시)

### 6-3. 지역 해금 · 환생
- 보스 클리어 시 다음 지역 해금.
- **환생(프레스티지)**: Stage 100+ 에서 가능, 스테이지·골드·공격력 강화를 리셋하고 **'이세계의 별'** 획득 → 영구 공격력/골드 보너스. (악세사리·파트너는 유지)

## 7. 방치 보상
- 접속 종료 시각 저장 → 복귀 시 `경과시간(최대 8h) × 분당 골드·드랍` 정산 팝업.
- 광고 대신 웹 환경 고려: 보상 2배 버튼은 **젬 소모** 또는 (추후) 광고.

## 8. 재화
| 재화 | 용도 | 획득 |
|---|---|---|
| 🪙 골드 | 공격력/스탯 강화 | 전투, 방치 |
| 💎 젬 | 악세사리 소환, 편의 기능 | 퀘스트, 보스 최초 클리어, 업적 |
| 🔩 강화석 | 악세사리 강화 | 분해, 보스 |
| 🎲 재굴림석 | 옵션 재굴림 | 이벤트, 일일 던전 |
| ⭐ 이세계의 별 | 환생 영구 보너스 | 환생 |
| ⚡ 에너지 | 던전 입장 | 시간 회복(30/30) |

## 9. 콘텐츠 / 메타
- **일일 퀘스트**: 몬스터 N마리, 강화 N회, 소환 1회 → 젬
- **업적**: 스테이지 도달, 악세 등급 수집
- **도감**: 몬스터/악세사리 수집 (수집 완료 시 영구 스탯)
- **던전(에너지 소모)**: 재굴림석/강화석 던전, 보스 러시
- **편의점 이벤트**: 컨셉 연결. 주기적으로 '편의점'이 이세계에 등장 → 한정 상점(기간 한정 악세사리)
- **랭킹**: 최고 스테이지 (서버 도입 이후)
- (후순위) 시즌 패스, 미니게임, 우편함

## 10. UI / 디자인 가이드 (첨부 이미지 참고)

### 레퍼런스 분석
- **이미지 1 (DS풍 도트 RPG)** → 따뜻하고 통통한 도트 캐릭터, 밝은 초원 배경(원경 바위산·구름 패럴랙스), **하단에 갈색·황금 테두리 패널**, 노란 포인트 라벨(아이템 획득 띠), 네모난 아이콘 카드 슬롯.
- **이미지 2 (모바일 방치형)** → 상단 재화 바(⚡ 🪙 💎), 중앙 캐릭터 + 웨이브 배너(리본), 좌우 세로 아이콘 메뉴, 큰 노란 **START 버튼**, 하단 5탭 네비게이션.

### 합성 방향
- **화면 구조(세로 모바일 기준)**
  1. 상단 HUD: 프로필·레벨 / ⚡에너지 / 🪙골드 / 💎젬 / 설정
  2. 전투 뷰(상단 약 45%): 횡스크롤 필드, 스테이지 리본 배너(`STAGE 1-3`), 몬스터 HP 바, 데미지 숫자
  3. 좌우 아이콘 메뉴: 퀘스트·이벤트·랭킹·편의점 상점 등 (이미지 2 방식)
  4. 하단 패널(55%): 이미지 1의 **갈색 우드+황금 테두리** 프레임 안에 탭 콘텐츠
  5. 최하단 탭 5개: **성장 / 악세사리 / 모험(전투 홈) / 파트너 / 상점**
- **PC 화면**: 가운데 모바일 비율(9:16) 프레임 고정 + 양옆 배경 일러스트.

### 아트 규칙
- 도트 캐릭터 32×32 기준, 1px 어두운 외곽선, 정수 배율 확대(`image-rendering: pixelated`)
- 폰트: 둥근 도트체 (예: Galmuri / DotGothic16)
- 패럴랙스 3겹 (원경 산·중경 나무·근경 풀), 몬스터는 사선 점프 모션으로 귀여운 느낌
- 등급 컬러 테두리 + 반짝임 이펙트로 레어 획득 연출 강조

### 화면 목록
1. 타이틀 → 이세계 도착 컷신 → 이름 입력 → 캐릭터 선택 → 파트너 선택
2. 메인(전투) 화면
3. 성장 탭 (공격력 강화 리스트)
4. 악세사리 탭 (장착 슬롯 5 + 인벤토리 그리드 + 상세/강화 팝업)
5. 소환 화면 (뽑기 연출, 천장 카운트)
6. 파트너 탭
7. 상점 / 퀘스트 / 업적 / 도감 / 설정
8. 방치 보상 팝업

## 11. 수치 밸런스 초안
| 항목 | 공식 |
|---|---|
| 플레이어 DPS | `ATK × AS × (1 + CRIT×CDMG)` × 악세 보정 |
| 스테이지 n 몬스터 HP | `10 × 1.18^n` |
| 공격력 강화 비용(Lv N) | `50 × 1.12^N` |
| 악세 강화 비용(Lv N) | `100 × 1.25^N` 골드 + 강화석 |
| 등급 확률(소환) | 일반 45 / 고급 30 / 희귀 17 / 영웅 6 / 전설 1.8 / 신화 0.2 (%) |
| 오프라인 | 최대 8시간, 효율 70% |

목표 페이싱: 초반 5분 안에 스테이지 5, 첫 악세사리 획득, 첫 보스 도전.
