# 리:이세계 (RE: ISEKAI)

웹 기반 횡스크롤 방치형 RPG 프로토타입. 기획서: [`docs/GDD.md`](docs/GDD.md)

## 실행
빌드 없이 정적 파일입니다. 아무 정적 서버로 열면 됩니다.

```bash
python3 -m http.server 8000   # → http://localhost:8000
```
(`index.html`을 직접 열어도 동작합니다)

## 웹에서 플레이 / 저장
- 배포: GitHub Pages (`.github/workflows/pages.yml`) · 설정법은 [`docs/DEPLOY.md`](docs/DEPLOY.md)
- 로그인: 이름 + 숫자 4자리 비밀번호 → 기록을 **브라우저에서 암호화**해서 저장 (서버 연결 시 Worker가 GitHub `saves` 브랜치에 커밋)

## 구현된 것
- 오프닝(트럭 → 편의점 앞 "여긴 어디지?") → 이름 → 캐릭터 4종 → **파트너 생성**(도트 파츠 조합 + 색상 변경 + 이름/성격/대사 직접 입력)
- 자동 전투(횡스크롤, 지역 4개·몬스터 12종·보스), 스테이지/보스 도전, 사망·부활
- 성장(공격력/공속/치명타/치피/체력, ×1/×10/MAX), 무기 강화 +20
- 악세사리 5슬롯·6등급·랜덤 옵션, 강화·옵션 재굴림·합성·분해, 소환(천장 90)
- 파트너 역할별 자동 스킬, 애정도, 응원 대사 말풍선, 선물
- **플레이어 조우**(대결/나눔/회복/버프/무기 강화, 현재는 NPC 분신) · 친구 신청 · 인연 포인트
- 방치 보상(최대 8h), 일일 퀘스트/무료 선물, 환생(STAGE 100+), 자동 저장
- ⚙ 설정의 테스트 메뉴(조우 즉시 발생, 스테이지/재화 추가)

## 구조
- `js/sprites.js` 코드로 그리는 도트 스프라이트(파츠·팔레트 스왑·자동 외곽선) · `js/game.js` 상태/전투/규칙 · `js/ui.js` 화면
- `assets/ui/` UI 에셋(9-slice 패널·버튼 등)
